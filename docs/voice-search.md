# 车机语音点歌（Flyme，实验）

AM 顶栏导航右侧的麦克风按钮：说一句话，AM 在本机识别后执行。录音不会上传，识别也不需要联网；只有搜歌时会照常请求 Apple Music 目录。

## 能说什么

| 说法 | 结果 |
|---|---|
| 暂停 / 停一下 | 暂停 |
| 继续 / 继续播放 / 播放 | 继续播放 |
| 下一首 / 换一首 / 切歌，上一首 | 切歌 |
| 播放周杰伦的歌、我想听周杰伦的晴天、来一首晴天 | 在 Apple Music 搜歌并播放第一首，其余结果作为队列 |
| 第三个 / 播放第二首 / 选第十二项 | 播放当前页面列表里的第 N 首：打开的专辑或歌单、歌手页的热门歌曲，或搜索页的歌曲区 |
| 其他任何一句话 | 当作歌名或歌手去搜 |

聆听时会暂停当前的歌，听完按指令继续或换歌。再点一次麦克风或点浮层外面可以取消。

## 组成

- 识别：[sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) 2.0.1（Apache-2.0），模型 `sherpa-onnx-streaming-zipformer-small-ctc-zh-int8-2025-04-01`（流式，int8，约 26 MB），只打包 arm64。
- 指令解析：`integration/VoiceCommand.kt`，固定规则，没有语言模型。
- 引擎与模型不进仓库。CI 从 sherpa-onnx 官方 Release 下载并校验 SHA-256；本地构建要先把 AAR 放到 `app/libs/`，把 `model.int8.onnx` 和 `tokens.txt` 放到 `app/src/flymeGecko/assets/asr/`。没有模型时麦克风按钮不显示。

## 已知限制

- 模型以中文为主，英文歌名、歌手名识别率较低。
- 车机自带语音助手可能一直占用麦克风，这时会提示"麦克风正被其他应用占用"，需要实车确认。
- 安装包因此增加约 57 MB：引擎约 31 MB，模型约 26 MB。
