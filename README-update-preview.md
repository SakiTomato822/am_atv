# 下一版更新整理（暫稿）

整理日期：2026-10-26。

對照基準為上一個正式 release：
[AM for TV v0.6.1](https://github.com/Sam20060720/am_atv/releases/tag/v0.6.1)，
對應 commit `558caa2`。以下涵蓋此後的所有修改，包含前面三個已提交的修復與這次的登入相容版。

目前 APK 仍沿用 `0.6.1 / versionCode 14`，新版本號尚未決定，也尚未建立新的 release。

## 這次最有感的變化

- 歌詞捲動更連貫，修復重疊句跳動、長句超出邊界，以及多語言發音對齊問題。
- 歌詞翻譯／發音重新提供獨立開關與語言設定，載入與切換時保留穩定的原文。
- 增加 Gecko 登入版，供系統 WebView 顯示白頁或登入表單無法載入的電視使用。
- 媒體庫支援繼續載入，並修復舊歌曲 ID 導致部分曲目無法播放的情況。
- 改善登出、重新登入與帳號切換的清理和時序，增加低效能模式與封面快取容量上限。

## 歌詞顯示與翻譯／發音

| 項目 | 相較正式版的變更 |
| --- | --- |
| 重疊句捲動 | 調整合唱、主唱與背景人聲的可視範圍計算；盡可能保留上方仍在唱的內容，在下方確實放不下時才上推，修正反覆跳回或過早捲走的情況。 |
| 超長歌詞 | 依實際可用寬度分行；正常情況保留同一詞的音節群，單一群組過寬時仍可拆分，避免整句跑出歌詞欄位。 |
| 多語言對齊 | 統一同一列的字體基準線、上下空間與發音區高度，改善韓文、英文、中文等混排時的高低落差。 |
| 發音位置 | 每段發音靠左對齊對應原文字詞，同列各段保留一致的垂直位置。 |
| 翻譯與發音同開 | 自動縮小對應字級、行高與間距，減少單句佔據過多畫面；主唱與背景人聲分別計算。 |
| 設定入口 | 播放頁右下角新增翻譯設定按鈕，放在歌詞按鈕左邊。可分別切換翻譯與發音，設定翻譯目標語言及發音字種／語言，並保存偏好。 |
| 原文與背景人聲 | 原文、翻譯、發音及背景人聲分開解析與合併，保留各自時間資訊，避免把替代語言重複當成原文，或因啟用翻譯而丟失背景人聲資料。 |
| 載入閃爍 | 明確區分載入中、可顯示、確定無資料及暫時失敗；切換語言時保留已經取得的原文，完成解析後再更新。 |
| 冷啟動預載 | 還原目前曲目且登入／請求條件就緒後即可載入歌詞，不必先按播放，也不必等待底層音訊播放器準備完成。 |
| 語言快取 | 翻譯／發音設定納入快取識別，避免切換後誤用另一語言的結果，或把只有原文的舊快取誤當作增強歌詞已載入。 |

翻譯與發音使用 Apple 提供的資料。原文語言取自歌曲；使用者可選擇目標語言，可用的翻譯／發音仍受歌曲與資料來源限制。

## 登入、登出與 Gecko 相容版

| 項目 | 相較正式版的變更 |
| --- | --- |
| 系統 WebView 相容性 | 補上 Provider／renderer 異常處理、載入與資源錯誤診斷；保留 Apple 彈出視窗的 opener 關係。 |
| 登入等待 | 載入、表單可互動與錯誤各自處理，等待輸入帳密、雙重驗證及允許授權時沒有 App 設定的失敗倒數。 |
| 黑色狀態列遮擋 | 原生載入／錯誤訊息改放獨立列，避免蓋住 Apple 登入框與允許按鈕，表單可操作時收起狀態列。 |
| 重複登入與舊回應 | 增加入場與回應狀態保護，避免重複啟動登入，並防止已取消或過期的登入流程覆蓋目前帳號狀態。 |
| 登出清理 | 清除目前播放、佇列、歷史及持久化 session；阻止尚未完成的背景寫入把舊資料寫回。 |
| Web 登入狀態重設 | 登出時只記錄待清理狀態，下一次系統 WebView 登入前再完成 Cookie／WebStorage 清理，避免登出時初始化缺失的 WebView 而顯示連線失敗。 |
| 浮動 console | 登入頁右上顯示引擎、頁面導向、腳本及網路錯誤；不取得焦點或攔截操作，MENU 可收合。訊息數量與文字量有上限，並遮蔽常見敏感資料及 URL 參數。 |
| iPhone 登入按鈕 | 兩種登入引擎共用網頁 hook，隱藏「使用 iPhone 登入」選項及對應的 iOS 提示；若原本聚焦於該按鈕，移回密碼登入。密碼、忘記密碼與驗證碼入口保留。 |

### Gecko 版的用途

正式版只有系統 WebView。這次新增第二種建置選項，**只替換登入使用的瀏覽器核心**；播放器與音樂串流繼續使用原生 MusicKit。

- 使用內建 GeckoView，降低對電視系統 WebView 版本與 Provider 狀態的依賴。
- 登入在獨立程序中執行，以私人 session 隔離每次登入，結束時關閉登入視窗與清理其 context。
- 本機 bootstrap 使用隨機連接埠與一次性的隨機路徑；Apple 帳號頁維持 HTTPS。
- 保留 Apple 授權視窗的回傳通道，修正開發中遇到的 `Getting ready` 卡住與完成授權後 `Unauthorized` 問題。
- 遙控器上／下對應欄位切換；確認鍵啟用控制項，文字欄位則叫出鍵盤。左右保留文字游標操作，鍵盤顯示時交給鍵盤處理方向鍵。

## 媒體庫、播放與搜尋

| 項目 | 相較正式版的變更 |
| --- | --- |
| 媒體庫 24 筆限制 | 歌曲與歌單改為逐頁載入；保留既有項目，在列表尾端提供繼續載入／失敗重試，不再受原本 24 筆截斷限制。 |
| 分頁重複與焦點 | 依媒體庫資源識別去重，保留不同媒體庫項目；載入下一頁時維持遙控器焦點，避免最後一頁或重試時跳位。 |
| 舊歌曲 ID | 透過媒體庫原始資源及 Apple 官方等價曲目對照，解析帳號所在地區可用的播放 ID；同一路徑也涵蓋一般曲庫歌曲與舊佇列。 |
| 佇列與還原 | 播放 ID 修正會回寫目前曲目、佇列與持久化資料，保留原始來源和重複入列的項目，避免重開後又使用舊 ID。 |
| 曲庫錯誤分類 | 分開處理真的下架、授權失敗及暫時網路問題；暫時錯誤採有限次重試，避免把連線問題直接當作歌曲不可播放。 |
| 遙控器快轉／倒轉 | 改走有狀態檢查的播放位移操作，避免冷啟動還原中、播放器尚未建立時直接呼叫 seek 而崩潰。 |
| YTM 推薦失敗 | 推薦請求失敗或逾時時，嘗試改用 Apple Music 原生電台取得接續曲目。 |
| 地區曲庫 | 搜尋、排行榜、電台及歌曲比對改用登入帳號的 storefront；未登入時使用預設地區。 |
| 搜尋結果 | 搜尋失敗會清除舊結果；執行搜尋後的無結果畫面不再混入最近播放。只有初始未搜尋狀態顯示最近播放。 |

## 資源與建置

| 項目 | 相較正式版的變更 |
| --- | --- |
| 低效能模式 | 設定頁新增切換，停用動態封面播放及較重的背景繪製，降低低規電視盒的解碼與繪製負擔。 |
| 螢幕常亮 | 移除 Activity 的無條件常亮；依播放中或等待播放狀態控制，暫停／閒置時可交回系統螢幕保護與休眠。 |
| 封面快取 | 加入最高 256 MiB 的容量上限，並保留既有磁碟空間檢查。 |
| 前台播放服務 | 新增 `mediaPlayback` 前台服務及播放通知，提高播放時的程序優先權。播放器與 Activity 生命週期的完整拆分尚未完成，Activity 重建與長時間背景播放仍需驗證。 |
| R8 警告 | 建置時只對官方 MusicKit AAR 中缺少 stack-map frames 的類別重算驗證資料；保留原始 SDK 檔案，原有 songId 修補範圍不變。最新完整建置的 R8 警告為 0。 |
| Gecko APK 體積 | 改為壓縮原生程式庫，並支援只打包 ARM32 或 ARM64。原本約 333.6 MiB 的雙架構 Gecko APK，通用版降為約 169.8 MiB；BRAVIA 使用的 ARM32 版約 94.3 MiB。 |

### 目前可用的 APK

| 檔案 | 用途 | 約略大小 |
| --- | --- | --- |
| `dist/AMATV-0.6.1.apk` | 系統 WebView 登入版 | 20.6 MiB |
| `dist/AMATV-0.6.1-gecko.apk` | 內建 Gecko；ARM32／ARM64 通用 | 169.8 MiB |
| `dist/AMATV-0.6.1-gecko-arm32.apk` | 內建 Gecko；只供 ARM32 裝置，例如這台 BRAVIA | 94.3 MiB |

兩種引擎版本使用相同 package／簽章，會互相覆蓋安裝並保留 App 資料。原生程式庫壓縮會減少 APK 檔案大小，安裝時仍需解壓所選架構，因此 APK 大小不等於安裝後用量。

建置方式與單一架構選項見 [APK 與原始碼發佈說明](docs/standalone-distribution.md)。
